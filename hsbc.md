# 💳 HSBC — Data Engineering Insights (26–30 LPA)

### 🧠 Overview
HSBC’s interviews test **real-world reliability, compliance, and architectural depth** — ideal for enterprise-scale data engineers.

---

## ⚙️ Core Questions
- Design a **real-time financial pipeline** processing millions of transactions.  
- Ensure **data consistency** across distributed systems.  
- Handle and prevent **duplicate production data**.  
- Manage **schema evolution** across downstream dependencies.  
- Debug **slow-running Spark jobs** in production.  
- Plan a **cloud migration** from on-prem data warehouse to the cloud.  
- Secure **PII data** in data lakes ensuring compliance.  
- Troubleshoot **Kafka message delays** and lags.  
- Execute **emergency recovery** if a data pipeline fails during peak load.  
- Manage **data partitioning** to avoid skew and improve query performance.  
- Build **monitoring and observability** for pipelines.  
- Join **huge datasets** beyond memory limits.  
- Perform **backfills** without affecting live systems.  
- Identify bottlenecks in **long-running batch jobs**.  
- Handle **late-arriving time-series data** efficiently.

---

## 💡 Takeaway
HSBC focuses on **reliability, compliance, and recovery mindset** — they want engineers who can **design for failure** and ensure **business continuity**.
