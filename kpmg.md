# ☁️ KPMG — Data Engineer (18 LPA | Azure Stack)

### 🧠 Overview
KPMG’s interview process dives deep into **Azure-based modern data architectures** — focusing on ADF, Databricks, and Synapse integration.

---

## ⚙️ Round 1 – Technical
1️⃣ Design **batch + streaming ingestion** in ADF → ADLS → Synapse.  
2️⃣ Implement **incremental loading (CDC)** using watermark or change tracking.  
3️⃣ Optimize **Spark jobs** with skew or OOM errors.  
4️⃣ Explain why **too many small Parquet files** hurt performance — and how to fix it.  
5️⃣ SQL: Find the **2nd highest salary** using window functions.

---

## ⚙️ Round 2 – Advanced Technical Design
1️⃣ Design a **multi-tenant data warehouse** combining real-time + batch workloads.  
2️⃣ Handle **heavy shuffle** in Spark joins — discuss broadcast, salting, and partitioning.  
3️⃣ Walk through the **end-to-end data flow:** Source → ADF → ADLS → Databricks → Synapse → Power BI.  
4️⃣ Recover **partial loads** in ADF without full reloads.  
5️⃣ Design a **CDC framework** using SQL Server + ADF + Event Hub.  
6️⃣ Root cause a **batch runtime increase** from 1h → 3h.

---

## 👥 Round 3 – Managerial
- Discuss a project where you improved **performance and cost efficiency**.  
- Explain how you managed **conflicts between business and engineering priorities**.  
- Describe a **tight-deadline delivery** story.  
- Detail how you maintain **data quality and monitoring** in Azure pipelines.

---

## 💡 Takeaway
KPMG tests both **technical mastery and architectural reasoning** — you must blend **engineering precision with business alignment.**
